For humans & the agents they work with

Your personal tasks.
Your agents' tasks.
One app.

LocalCortex is a native Mac & iOS task manager built around Efforts — each one pairs a task list with a real folder on disk. CloudKit keeps everything in sync, you own every byte, and there's a first-class surface for the coding agents you work with.

macOS 26.5+  ·  iOS 18+  ·  CloudKit sync

Efforts

A project's tasks and its folder, linked.

An Effort is more than a project name. It's a task list and a real directory on disk. Create an Effort and LocalCortex materializes the folder — your code, notes, and assets live right there.

One link, two halves

The task list tracks what to do; the folder holds the work. LocalCortex keeps the link between them and never copies your files anywhere.

You pick the root

Choose a root folder in Settings. Each Effort gets a stable subfolder under it, so paths stay predictable across machines.

Tasks

GTD-style tasks that fit how you actually work.

Every Task carries a clear status, defer and due dates, recurrence, nested subtasks, notes, a Today focus flag, and a marker for who's working on it — you or an agent.

Four clean statuses

Open, In Progress, Completed, Blocked. Completing a parent finishes the whole subtree; reopening a child reopens its ancestors.

Defer, due, repeat

Recurring tasks with weekday-aware patterns — “every Wednesday”, “last Sunday of the month” — on a fixed or after-completion basis.

Today, on your terms

A manual Today flag surfaces what matters now, independent of due dates.

CloudKit sync

Structured data syncs. You own the bytes.

Efforts and Tasks sync across your Mac, iPhone, and iPad through CloudKit — private to your account, no servers of ours in the middle. Files are a separate, deliberate choice.

Bring your own sync

Want the folders to travel too? Point the Efforts root at iCloud Drive, Dropbox, or Google Drive. LocalCortex never syncs file bytes itself.

Honest when it's off

If sync can't reach CloudKit, the app says so plainly in Settings rather than silently going quiet.

For coding agents

Your agents can read your tasks and find your files.

LocalCortex exposes a first-class automation surface on macOS. Claude Code, Codex, and other agents can list and update your tasks, claim work, and resolve an Effort's folder path — then use their own tools to read and edit your project. File bytes never cross the boundary.

  • efforts_listList all Efforts
  • tasks_listSummaries per Effort
  • tasks_getFull task detail
  • files_pathResolve a folder path
  • tasks_createAdd a task
  • tasks_updatePatch fields, claim work
  • tasks_completeFinish or reopen

One surface, full parity

An always-on JXA Automation surface (AppleScript / JavaScript for Automation) drives the same store the UI uses, so there's a single writer by construction — every agent command and every click lands in one consistent state.

Sane trust model

The write surface is tasks-only — no Effort create/delete, no file mutation, no task deletion. The JXA Automation surface is TCC-gated per sender, so macOS asks before any agent is allowed in.

Quick Find & smart lists

Find anything in a keystroke.

Press ⌘O to search across every Effort and open task. The sidebar's smart lists — Today, Anytime, All Tasks — keep the view you want one tap away.

Smart lists

Today, Anytime, and All Tasks, plus Hide Completed and Hide Deferred filters to keep the noise down.

Global search

One field, every task, every Effort — results as you type.
