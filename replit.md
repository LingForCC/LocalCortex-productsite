# LocalCortex product site

## Running on Replit

This is a dependency-free static website built with HTML, CSS, and vanilla JavaScript.

- Replit workflow: `Start application`
- Server command: `python3 -m http.server 5000 --bind 0.0.0.0`
- Preview: use the Replit Preview panel after starting the workflow

There are no required environment variables or external services for the current site.
