# Screenshots

The site picks screenshots up **by filename**: drop a file into this folder
with one of the names below and it appears on the page automatically — no
HTML edits needed. Until a file exists, the page shows a styled placeholder
in its place (each placeholder prints the filename it expects).

Images are embedded **as-is, with no device chrome** — no window title bar,
traffic lights, or bezel is drawn around them, so use clean app/window shots.

## Names

| Filename                 | Section                | Size (px)   |
| ------------------------ | ---------------------- | ----------- |
| `hero-collage.png`       | Hero visual            | 1600 × 1200 |
| `efforts-mac.png`        | Efforts section        | 1440 × 900  |
| `task-detail-mac.png`    | Task detail section    | 1440 × 900  |
| `agent-activity-mac.png` | Agent activity section | 1440 × 900  |
| `sync-mac.png`           | Sync across your Macs  | 1440 × 900  |
| `agent-plugins-mac.png`  | Agent plugins section  | 1440 × 900  |

`.jpg` and `.webp` also work with the same base name (e.g. `sync-mac.jpg`).

## Tips

- **2× / Retina:** export at twice the listed size for crisp rendering on
  high-DPI screens; the page scales the image to the slot width.
- **Any aspect ratio works** — the image renders at full slot width with its
  natural height, so the listed sizes are guidance, not requirements.
